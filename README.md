\# SkillSync



\## Campus Skill Exchange \& Peer Learning Platform



SkillSync is a web-based platform that allows college students to

exchange skills, discover learning partners, schedule learning

sessions, and share knowledge without monetary exchange.



\## Technologies



\- React.js

\- Django

\- Django REST Framework

\- MySQL / SQLite

\- Git \& GitHub



\## Main Features



\- Student Registration \& Login

\- Student Profiles

\- Skill Management

\- Skill Discovery

\- Skill Matching

\- Swap Requests

\- Session Scheduling

\- Reviews \& Ratings

\- Notifications

\- Admin Dashboard

\- Analytics



\## Project Structure



\- `frontend/` – React frontend

\- `backend/` – Django backend
